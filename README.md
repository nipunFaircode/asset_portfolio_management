# Portfolio Management System

Portfolio Management module to manage and track personal investments across multiple asset classes. The initial release will support:

* Stocks
* Bonds
* Fixed Deposits
* Savings Accounts

Future asset classes should include:

* Provident Fund (PF)
* Public Provident Fund (PPF)
* National Pension System (NPS)

The system should provide consolidated portfolio reporting, asset performance tracking, cash flow monitoring, and return calculations.
